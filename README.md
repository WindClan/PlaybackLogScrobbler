# playback.log Scrobbler

Insanely simple program that scrobbles RockBox's playback.log since the new scrobbler plugin requires manually converting it to the old format.

This program uses lastfm-java 0.1.2, jaudiotagger 3.0.1, and simple-directory-chooser 0.0.3

### NOTE:
This program seems to have some issues with Oracle Java 8 JRE, it is only tested working with Zulu Java 8 JDK
